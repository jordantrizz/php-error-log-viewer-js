⚠️ CORS may block remote URLs

Browsers block cross-origin HTTP requests unless the remote server sends this header:

Access-Control-Allow-Origin: *

If the fetch fails with a CORS error, try one of these workarounds:

  • Download the file to your machine and use the Upload tab instead
  • Copy & paste the log content into the Paste tab
  • If you control the server, add the CORS header above to its response
